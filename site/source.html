The engine is private. The evidence is not.

This repository cannot be public: boundary.json holds one person's actual browsing, and publishing the engine publishes their life. So here is the part a judge can check — real excerpts, regenerated from the working tree every time this page is built.

iThe shape

Sixteen crates, one promise.

The engine is not a wrapper around a model. It is a deterministic fold: events in, episodes of attention out, episodes joined into bodies of work. Replay the same log and you get the same boundary, byte for byte.

iiThe supreme court

Six ways a person outranksthe machine.

Evo does not learn. There are no weights, no fine-tuning and no feedback loop. The person legislates; the engine adjudicates; the log remembers. These are the six declarations, exactly as they ship.

crates/evo-threads/src/types.rs · 67–98
/// The supreme court of attribution. Sparse, rare, and never overridden by
/// inference. Declarations are the only path by which two established threads
/// may ever merge.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum Declaration {
    /// "These belong together." If each side lives in a different thread,
    /// those threads merge. This is the sole merge path in the system.
    SameWork { a: String, b: String },
    /// "These are separate." A standing constraint: no future assignment may
    /// place the two sides into one thread based on inference.
    SeparateWork { a: String, b: String },
    /// "This is not my work." Permanent quarantine: the resource is stripped
    /// from every view and never becomes evidence again.
    NotMine { resource: String },
    /// "This surface is of a class." The person's own word about a subject
    /// other events have already established — "this is not work", "this is
    /// media". A classification gates *founding and titling only*: the subject
    /// may never anchor or name a work, and any anchor it already carried is
    /// demoted back to context. It is never removed from a body of work — the
    /// non-deletion guarantee holds, and it keeps whatever attention it earned.
    /// Evo ships no default class; silence produces no classification.
    Classified { resource: String, class: String },
    /// "Do not show this body of work on the default surface." Evidence is
    /// retained and the work remains retrievable.
    WorkDismissed { work: String },
    /// The user's lifecycle correction for one member of a body of work.
    MemberState {
        work: String,
        member: String,
        state: MemberState,
    },
}
iiiThe prohibition

Not a preference.A standing constraint.

This is the load-bearing line of the whole product. SeparateWork is not a score that tilts an inference — it is inserted into a set that every future assignment is checked against, and it is never removed.

vLocal-first, as a test

“No network” is checked,not claimed.

A promise in a README survives exactly as long as nobody is in a hurry. So it is a test: it walks every manifest in the workspace and fails the build if a network or TLS client ever appears.

crates/evo-desktop/tests/trust_constraints.rs · 131–152
fn nothing_in_the_workspace_can_transmit_what_evo_witnessed() {
    // Constraint C3. The observation log is a record of everything the person
    // did; a single HTTP client dependency is all it would take for a future
    // feature to send it somewhere. Evo must not have the capability at all.
    let root = repo_root();
    let mut offenders = Vec::new();
    for (path, text) in manifests(&root) {
        for forbidden in FORBIDDEN_NETWORK_CRATES {
            if let Some(line) = declares(&text, forbidden) {
                offenders.push(format!("{path}: {line}"));
            }
        }
    }
    assert!(
        offenders.is_empty(),
        "Evo must have no way to transmit what it witnessed, but these manifests \
         declare a network or TLS client:\n  {}\n\n\
         If a feature genuinely needs the network, it does not belong in Evo — \
         the product promise is that information never leaves the machine.",
        offenders.join("\n  ")
    );
}
viThe agent surface

Three tools. That isthe whole contract.

The service speaks MCP over stdio. Any agent — Kiro, Claude, anything that reads the spec — can ask where a resource belongs and get a decision with its evidence. The server is standard-library Python; there is nothing to install.

viiWhat is withheld

And why.

  • Corpusboundary.json — 10,392 real events from one person's machine, including search queries and documents. Never published, in any form.
  • Product shellThe macOS app, the capture layer and the voice pipeline are in the private tree. They are why the boundary can be derived at all.
  • AccessAsk, and we will add you to the repository. We would rather give a judge a real walkthrough than scrub a corpus and pretend it is the same thing.

Everything on this page is extracted from the working tree by tools/build_source.py at build time. If a line number moves, the page fails to build rather than showing you something plausible.
