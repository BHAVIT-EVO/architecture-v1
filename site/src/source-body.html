Source · read-only · no corpus

The engine is private. The evidence is not.

This repository cannot be public: boundary.json holds one person's actual browsing, and publishing the engine publishes their life. So here is the part a judge can check — real excerpts, regenerated from the working tree every time this page is built.

iThe shape

Sixteen crates, one promise.

The engine is not a wrapper around a model. It is a deterministic fold: events in, episodes of attention out, episodes joined into bodies of work. Replay the same log and you get the same boundary, byte for byte.

No model in the decision path · no HTTP client anywhere · no async runtime in the engine

iiThe supreme court

Six ways a person outranksthe machine.

Evo does not learn. There are no weights, no fine-tuning and no feedback loop. The person legislates; the engine adjudicates; the log remembers. These are the six declarations, exactly as they ship.


        

      

    

  


  

    

      

        
iiiThe prohibition

        

          
Not a preference.A standing constraint.

          
This is the load-bearing line of the whole product. SeparateWork is not a score that tilts an inference — it is inserted into a set that every future assignment is checked against, and it is never removed.

          

          

        

      

    

  


  

    

      

        
ivThe gate

        

          
It never asserts coverage.

          
Three things are hard-asserted against the committed corpus: no two labelled works fuse, no leisure resource anchors a work, and the same log replays to the same threads. The test reads the real event log — it is not a fixture.

          

          

        

      

    

  


  

    

      

        
vLocal-first, as a test

        

          
“No network” is checked,not claimed.

          
A promise in a README survives exactly as long as nobody is in a hurry. So it is a test: it walks every manifest in the workspace and fails the build if a network or TLS client ever appears.

          

        

      

    

  


  

    

      

        
viThe agent surface

        

          
Three tools. That isthe whole contract.

          
The service speaks MCP over stdio. Any agent — Kiro, Claude, anything that reads the spec — can ask where a resource belongs and get a decision with its evidence. The server is standard-library Python; there is nothing to install.
