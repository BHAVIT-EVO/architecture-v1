# Brand

## Colors
- Mark ground: `#0b2118`
- Path: `#f0ead8`
- Screen: `#8fe0a8`
- Fireflies: `#f4d98f`
- Wordmark uses `currentColor`: `#f0ead8` on dark backgrounds, `#10241b` on light backgrounds.

## Clear space
At least the height of the mark's glowing screen square on every side of the mark or lockup.

## Minimum sizes
- Mark: 16px
- Lockup: 120px wide
- Wordmark: 48px wide

## Rules
- Never stretch, rotate, outline, add shadows, place on busy photos, or put the wordmark in a different font.
- On light backgrounds use the same dark mark; never an inverted one.

## Source files (use byte for byte)
- `design/brand/evo-icon.svg` — app icon (macOS padding built in)
- `design/brand/evo-mark.svg` — tight mark for UI, web, favicons
- `design/brand/evo-wordmark.svg` — monoline "evo" (currentColor)
- `design/brand/evo-lockup.svg` — mark + wordmark
- `design/brand/evo-menubar-template.svg` — single-color black, for menu bar
